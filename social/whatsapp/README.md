# WhatsApp Community — BehaviorOS

> Curto, conversacional, CTA para comunidade com valor educacional. Não-spam.

## Estrutura

`onboarding/`, `announcements/`, `educational/`, `community/`, `weekly/`, `events/`, `launches/`

Todo LinkedIn importante tem adaptação WhatsApp (ver `linkedin/weekly/WEEK-01.md`).

## Template

```
> BOS-WA-XXX · Source: BOS-LINKEDIN-XXX · Pillars [X] · Status STABLE

👋 Hook (1 linha, emoji permitido mas contido)

Body (3-5 linhas, 1 conceito + 1 comando ou link)

CTA: school-bos/XX ou pnpm demo ou comunidade

— BehaviorOS Community • Learn. Build. Share. Contribute.
```

## Regras

- Máx 5 linhas + CTA. Links curtos (`school-bos/03-first-mission/README.md`).
- Todo `BOS-WA-XXX` rastreável a `BOS-LINKEDIN-XXX` + `BOS-LESSON-XXX`.
- CTA frequentemente aponta para comunidade quando apropriado, mas com valor educacional (não "clique aqui").

## Exemplos

Ver `onboarding/BOS-WA-001-welcome.md`, `weekly/WEEK-01.md`, `educational/BOS-WA-010-governance.md`.
