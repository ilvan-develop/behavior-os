# BehaviorOS School

> **Don't just learn BehaviorOS. Learn to think in BehaviorOS.**
>
> `Mission → Behavior → Governance → Pipeline → Evidence → Quality → Learning`

**BehaviorOS School** é a camada educacional canônica do BehaviorOS — inspirada no modelo [OpenCode School](https://opencode.school/), onde cada aula é uma experiência prática com prompt pronto para o agente.

## O que é

- **School = aprender.** Trilha estruturada do zero ao capstone.
- **Community = participar.** Ecossistema de conteúdo, workshops e contribuição.
- **GitHub = construir.** Código real, evidência observável.
- **BehaviorOS = produto.** O OS que orquestra tudo acima.

```
Human
  ↓
AI Team
  ↓
BehaviorOS
  ├── OpenCode  (execução)
  ├── Graphify  (conhecimento — 1202 nodes)
  └── LangGraph (runtime durável — 8 nodes + MemorySaver)
```

## Para quem

| Track | Público | Foco |
|-------|---------|------|
| **BOS Foundations** (A) | Usuários | conceitos, instalação, missions, workflows |
| **BOS Builder** (B) | Devs | SDK, DNA, engines, MCP, Graphify, LangGraph |
| **BOS Architect** (C) | Avançados | teams autônomos, governance empresarial, durable execution |

## Como começar

1. Leia `CURRICULUM.md` — visão completa do currículo.
2. Siga `LEARNING-PATH.md` — escolha sua track.
3. Comece em `00-orientation/README.md`.
4. Cada lição tem seção **OpenCode prompt** — cole no TUI.

## Princípios

- **Fonte da verdade = repositório real.** Nada é inventado; capacidades hipotéticas são marcadas `PLANNED`/`EXPERIMENTAL`.
- **Configuração ≠ integração.** Prova = `behavior-os/runtime/*.json` com `status: COMPLETED` + `graphify-out/graph.json` + `StateGraph` compilado.
- **Cada lição é verificável.** Comandos, testes e critérios de conclusão objetivos.
